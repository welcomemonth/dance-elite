# 部署说明（Docker）

镜像由 `scripts/build.sh` / `scripts/push-aliyun.sh` 构建并推送到阿里云个人版 ACR：

```
crpi-npw0av7ozhtwtzou.cn-hangzhou.personal.cr.aliyuncs.com/memos_meetmonth/dance-elite-json:<version>
```

编排文件为 `scripts/docker-compose.yml`（镜像内端口固定 8090，宿主机默认 18080）。

## 首次部署

```bash
# 1. 登录并拉镜像（个人版 ACR 需先登录）
docker login crpi-npw0av7ozhtwtzou.cn-hangzhou.personal.cr.aliyuncs.com
docker pull crpi-npw0av7ozhtwtzou.cn-hangzhou.personal.cr.aliyuncs.com/memos_meetmonth/dance-elite-json:latest

# 2. 准备配置与持久化目录（.env 模板见仓库根 .env.example，不入库）
mkdir -p /opt/dance-elite-deploy/data
cp .env.example /opt/dance-elite-deploy/.env   # 填入真实密钥后
cp scripts/docker-compose.yml /opt/dance-elite-deploy/

# 3. 启动
cd /opt/dance-elite-deploy
ELITE_ENV_FILE=/opt/dance-elite-deploy/.env ELITE_DATA_DIR=/opt/dance-elite-deploy/data \
  docker compose up -d
```

仓库内直接启动可省略两个环境变量（默认读 `../.env`、数据落 `scripts/data`）：

```bash
docker compose -f scripts/docker-compose.yml up -d
```

验证：

```bash
docker compose -f scripts/docker-compose.yml ps     # STATUS 为 healthy 即通过
curl http://127.0.0.1:18080/api/v1/ping
```

`/api/v1/ping` 见 `internal/router/router.go`；健康检查每 30s 调一次。

## 容器内路径

| 路径 | 用途 |
|---|---|
| `/opt/dance-elite` | 工作目录 + 挂载卷根；`DB_PATH` / `UPLOAD_DIR` 均相对此目录 |
| `/opt/dance-elite/dance-elite.db` | SQLite（当前 `.env` 的 `DB_PATH`） |
| `/opt/dance-elite/uploads/` | 证件照、音频、头像；**必须持久化**，否则重启丢文件 |
| `/usr/local/dance-elite/` | 二进制与 entrypoint，只读使用 |

容器以 `nonroot`（uid 10001）运行；entrypoint 启动前会把挂载目录 `chown -R` 给该用户。

## 环境变量要点

- **必填**：`JWT_SECRET`、`ID_CARD_HMAC_KEY`、`WECHAT_APPID`、`WECHAT_SECRET`、`ADMIN_INIT_PASSWORD`；缺失时容器启动失败，日志一次性列出缺失项。
- **`TZ=Asia/Shanghai` 必设**（编排文件已固定）：赛事状态自动流转、入库时间字符串（`+08:00`）都按该时区计算，镜像默认 UTC。
- `PAY_MOCK=false` 时还需 `WECHAT_MCHID`、`WECHAT_PAY_KEY`、`WECHAT_MCH_SERIAL_NO`、商户私钥、平台证书、支付/退款回调地址。
- `PUBLIC_BASE_URL` 填外网地址，用于拼接音频审核 H5 链接；为空时接口返回相对路径。
- 支付证书与大额私钥二选一：PEM 文本（`WECHAT_PAY_CERT` / `WECHAT_PAY_PRIVATE_KEY`）或文件路径（`*_FILE`，推荐只读挂载到 `/run/secrets/`）。两个同时设置会启动失败。**不要把只读文件挂到 `/opt/dance-elite` 下**——entrypoint 的 `chown -R` 会因只读文件报错退出。

## 常用操作

```bash
docker compose -f scripts/docker-compose.yml logs -f        # 看日志（单文件 10MB × 3 轮转）
docker compose -f scripts/docker-compose.yml restart
ELITE_IMAGE_TAG=1.0.1 docker compose -f scripts/docker-compose.yml up -d   # 升级镜像
docker compose -f scripts/docker-compose.yml down            # 停止（数据在宿主目录，不受影响）
```

备份：停容器后复制 `ELITE_DATA_DIR` 整个目录即可（SQLite 为 WAL 模式，运行中直接拷贝文件可能不一致）。

## 前置代理

小程序端要求 HTTPS 备案域名，容器自身不处理 TLS。Nginx 反向代理到 `127.0.0.1:18080`，并透传 `Host`、`X-Forwarded-For`、`X-Forwarded-Proto`；微信支付回调地址（`WECHAT_PAY_NOTIFY_URL`、`WECHAT_REFUND_NOTIFY_URL`）须指向该外部地址。
