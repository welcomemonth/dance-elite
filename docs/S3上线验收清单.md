### 端到端冒烟覆盖（`scripts/smoke/e2e.sh`）

后台登录 → 建赛季并激活 → 建赛事并发布 → 人工报名（含出生日期）→ 缺失出生日期返回 40001
→ 报名名单 total=1 / 资料 8 项 → 导出 xlsx → 人工退赛并释放名额 → 客服工单与关键字筛选
→ 看板 → 退款工单登记/同意（mock）→ 退款回调闭环（订单 refunded）
→ 负向：后台接口无 token 40101、静态目录穿越 404、微信回调坏签名 401。

复现方式：

```bash
# 1) 准备临时配置（不要指向生产库）
cat > /tmp/e2e-config.yaml <<'YAML'
server: {port: 18099, public_base_url: "http://127.0.0.1:18099", slow_request_ms: 500}
storage: {db_path: /tmp/dance-e2e/dance-elite.db, upload_dir: /tmp/dance-e2e/uploads}
log: {level: info, format: console}
auth: {jwt_expire_seconds: 7200}
admin: {init_username: admin}
scheduler: {status_tick_seconds: 60, order_expire_minutes: 15, refund_watchdog_minutes: 10}
YAML
mkdir -p /tmp/dance-e2e/uploads

# 2) 构建并启动（从仓库根 .env 读取密钥；APP_ENV=dev 走 mock 支付）
go build -o /tmp/dance-e2e/server ./cmd/dance-elite
set -a; . ./.env; set +a
CONFIG_FILE=/tmp/e2e-config.yaml APP_ENV=dev /tmp/dance-e2e/server &

# 3) 跑冒烟
BASE_URL=http://127.0.0.1:18099 bash scripts/smoke/e2e.sh
```

> 注意：脚本会写测试数据，只能对临时库运行。

## 6. 安全自检记录（代码审计）

| 检查项 | 结论 |
|---|---|
| 证件号明文 | 仅请求体内存使用，立即 HMAC 哈希；错误信息不含证件号；日志侧 `RedactText` + `MaskIDNumber` 兜底 |
| 后台接口鉴权 | `/api/v1/admin` 全部经 `AdminAuth`；写操作按 `RequireRole` 细分；已修正催收标记为 admin 专属 |
| 静态文件 | `gin.Dir` + `path.Clean`；`../` 穿越请求返回 404（已实测） |
| 上传安全 | 临时文件 → 校验 → 原子 rename；文件名为服务端随机生成；路径穿越有单测覆盖 |
| 回调验签 | 支付/退款回调均校验时间戳新鲜度、公钥 ID 与 RSA 签名；坏签名 401（已实测） |
| 请求体上限 | 文本 64KB、照片 11MB、音频 101MB、回调 1MB（`MaxBytesReader`） |
| 限流 | 登录 10/min、预下单 10/min、报名 1 次/5 秒、H5 审核 60/min、reveal-phone 10/min |
| 密钥 | 只经环境变量注入；镜像不内置 `config.yaml` 与 `.env` |

> 唯一已知限制：后台「停用管理员」的 token 吊销为进程内黑名单，进程重启后残留 token 最迟 2 小时自然过期（已在 API 文档 8.1 注明）。
